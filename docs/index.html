How a container deleted from Git survives an Argo CD sync

A step-by-step look at how Kubernetes managedFields compaction makes Argo CD (server-side apply) keep a container that is no longer in Git, and why a PUT does not have this problem. Every table and spec on this page is real API-server output, captured by the reproduction repo.

Based on How we scale deployments with a custom GitOps engine by Ramesh G. Iyer (LinkedIn Engineering).
